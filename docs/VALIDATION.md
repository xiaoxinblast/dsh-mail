## 当前明确限制

- 附件单文件下载/上传 50 MiB；附件批量打包 200 MiB；邮件导入单次 100 MiB，恢复包展开 1 GiB。较大的导出返回本机路径。
- 邮件/附件导出及导入当前为同步业务调用，尚未全部转换为可取消长任务；批量邮件整理和文件夹复制使用持久任务队列。
- 联系人按分组字段管理；收件人补全已实现，完整往来统计视图未实现。
- HTML 正文在暗色外壳内仍使用白底阅读容器，避免改变邮件原有配色导致不可读。
- 单封移动前缓存其附件以保护来源引用；超过当前附件限制的移动会明确失败，不冒险删除来源。

只有真实账号由用户在设置中连接后，才能完成第一项；自动化测试不代替这一验收。
